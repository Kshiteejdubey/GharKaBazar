# CSS Standards Guidelines

1. No inline CSS — never use style="".
2. No use of !important.
3. Use CSS variables for all colors and font families.
4. Never use the id attribute.
5. Use Grid and Flex as the primary layout system.
6. Desktop-first but naturally responsive.
7. Avoid fixed dimensions.
8. Minimize media queries.
9. Write scalable and reusable layout patterns.
10. Use proper spacing systems.
11. No layout hacks.
12. Components must wrap naturally.
13. Avoid deep nesting and high specificity.
14. Maintain consistent design logic.
15. Convert screenshots into scalable layouts.
16. Keep the UI structure clean and extendable.
17. Performance-aware styling.
18. Reduce future responsive effort.
19. Layouts should behave like "Anti-Gravity".
