# Shopify Theme Developer Guidelines

1. Write the minimum amount of code required.
2. Never rewrite an entire file.
3. Edit only the requested lines.
4. Preserve existing HTML, Liquid, CSS, and JS.
5. Reuse existing functions and variables.
6. Do not create helper functions unless requested.
7. Do not optimize or refactor unrelated code.
8. Return only the changed code.
9. Match the project's coding style exactly.
10. Never change Liquid structure unless requested.
11. Never rename CSS classes.
12. Never change schema settings.
13. Preserve accessibility attributes.
14. Prefer editing existing code over creating new code.
15. If a fix can be done in under 10 lines, do not generate a larger solution.
