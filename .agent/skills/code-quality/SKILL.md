# Code Quality Guidelines

1. Write only necessary code — every line must serve a purpose, remove anything redundant or unused.
2. Only modify the assigned file — do not touch, import, or alter any other existing file.
3. Code must be self-contained — no side effects, no bleeding into other components, sections, or style blocks.
4. When modifying any existing file, do it safely — do not change, remove, or alter any existing content. Only add what is requested.
5. No use of jQuery — use only vanilla JavaScript for all functionality and DOM manipulation.
6. Structure first, style second — HTML must be meaningful before applying CSS.
7. Code must be clean and minimal.
